# 🌤️ SphereTempo - Weather App

Um aplicativo de previsão do tempo moderno, desenvolvido durante o Bootcamp da Generation Brasil. O projeto foca em boas práticas de JavaScript, consumo de APIs externas e testes automatizados.

## 🚀 Funcionalidades
- Busca de clima por nome de cidade (Geocodificação).
- Interface responsiva com design Glassmorphism (Apple Style).
- Tratamento de erros para cidades não encontradas ou falhas de rede.
- Documentação completa das funções usando JSDoc.

## 🛠️ Tecnologias Utilizadas
- **JavaScript (ES6+)**
- **Open-Meteo API** (Dados climáticos gratuitos)
- **Jest** (Testes Unitários)
- **CSS3** (Variáveis e Glassmorphism)
