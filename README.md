# 🌤️ SphereTempo

O **SphereTempo** é uma aplicação web de previsão meteorológica que combina um design moderno em Glassmorphism com dados precisos e astronômicos. O projeto foi desenvolvido como parte do bootcamp da Generation Brasil, focando em boas práticas de desenvolvimento, testes unitários e segurança.

## 🚀 Funcionalidades
- **Busca Global:** Encontre o clima de qualquer cidade através da integração com a Geocoding API.
- **Dados em Tempo Real:** Temperatura atualizada via Open-Meteo.
- **Informações Astronômicas:** Horários exatos do nascer e pôr do sol (Etapa 5).
- **Interface Responsiva:** Design elegante adaptável a diferentes dispositivos.

## 🛠️ Tecnologias Utilizadas
- **Frontend:** HTML5, CSS3 (Variáveis, Flexbox, Glassmorphism), JavaScript (Async/Await, Fetch API).
- **Testes:** Jest (Testes Unitários e Mocking).
- **API:** [Open-Meteo](https://open-meteo.com/).
